# ARYAN.OS V17 — EcoTrack Showcase Update

A static developer portfolio built with HTML, CSS, vanilla JavaScript, and optional Three.js holographic effects.

## Run locally
1. Extract the ZIP.
2. Open this folder in VS Code and run `index.html` using Live Server.
3. Internet access is needed for the Three.js module; the portrait remains as a fallback.

## Included
- Interactive portfolio interface and terminal
- WebGL holographic rings/particles with 2D portrait fallback
- HerbalAI and ShopEase screenshot galleries
- Resume PDF: `assets/resume/aryan-kushwaha-resume.pdf`
- Email: `aryankushwaha599@gmail.com`
- GitHub and LinkedIn profile links
- `.nojekyll` marker for GitHub Pages
- Step-by-step deployment guide in `DEPLOYMENT_GUIDE.md`

## Terminal commands
`help`, `about`, `skills`, `projects`, `contact`, `github`, `linkedin`, `resume`, `clear`

## Deployment
Follow `DEPLOYMENT_GUIDE.md`. Upload the **contents of this folder** to the root of a GitHub repository and enable GitHub Pages from `main` / `/(root)`.

## Limitations to know
- This is a static site; no backend or server-side contact form is configured.
- The 3D effect loads Three.js from jsDelivr and therefore requires internet access.
- The avatar portrait itself is 2D, surrounded by interactive 3D effects.
- No light/dark theme toggle is implemented in this version.
- The build was checked statically; live browser testing remains necessary before sharing it with recruiters.
